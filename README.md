# AROC-FOLD

Bimanual folding of children's clothes with LeRobot **SO-101** arms.

We start by reproducing [Ilia Larchenko's LeHome Challenge 2026 solution](https://github.com/IliaLarchenko/lehome_solution): 1st place in the sim round, 2nd in the real-world final ([blog](https://ilialarchenko.com/projects/lehome2026/), [tech report](https://arxiv.org/abs/2606.27163)). Then we improve on it, with real-world folding as the goal.

- Plan: [docs/ROADMAP.md](docs/ROADMAP.md)
- Reference notes: [docs/reference_notes.md](docs/reference_notes.md)

The reference solution is vendored as a git submodule in `external/lehome_solution`:

```bash
git clone --recurse-submodules https://github.com/<user>/AROC-FOLD
```
